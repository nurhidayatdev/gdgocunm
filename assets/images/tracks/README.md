# Panduan Upload Icon / Gambar Learning Path (Tracks)

Upload file gambar atau icon dengan latar belakang transparan (format `.png` atau `.svg` atau `.webp`) ke dalam folder ini: `assets/images/tracks/`.

Sistem sudah otomatis menghubungkan nama file dengan masing-masing track card. Jika gambar belum di-upload, web akan otomatis menampilkan fallback icon SVG bawaan.

### Nama File yang Dibutuhkan (Sesuai 8 Tracks):

1. **UI/UX Design**:
   - `uiux.png` (atau `uiux.svg` / `uiux.webp`)
   - Rekomendasi: Icon Figma / Desain UI, resolusi ~120x120px hingga 256x256px, transparan.

2. **Front-End**:
   - `frontend.png`
   - Rekomendasi: Icon React / Code / Web browser, transparan.

3. **Back-End**:
   - `backend.png`
   - Rekomendasi: Icon Server / Database / Cloud, transparan.

4. **Mobile**:
   - `mobile.png`
   - Rekomendasi: Icon Flutter / Smartphone / App, transparan.

5. **Robotics**:
   - `robotics.png`
   - Rekomendasi: Icon Robot / IoT / Microcontroller, transparan.

6. **AI / Machine Learning**:
   - `ai-ml.png`
   - Rekomendasi: Icon Brain / Google Gemini / Sparkle, transparan.

7. **Data Science**:
   - `data-science.png`
   - Rekomendasi: Icon Data chart / Analytics / BigQuery, transparan.

8. **Cyber Security**:
   - `cyber-security.png`
   - Rekomendasi: Icon Shield / Lock / Security, transparan.

---
> **Catatan:** Setelah gambar di-upload dengan nama file di atas, gambar tersebut akan langsung muncul di dalam card carousel Learning Path secara otomatis tanpa perlu mengubah kode lagi!
