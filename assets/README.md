## 💡 Cara Mengganti Foto / Logo

1. **Format Gambar yang Didukung**: `.jpg`, `.png`, `.webp`, `.svg`.
2. **Ukuran yang Disarankan**:
   * **Foto Team**: Rasio 1:1 (persegi), resolusi minimal `400 x 400 px`.
   * **Foto Galeri**: Rasio 16:9 atau 4:3, resolusi minimal `800 x 500 px`.
   * **Poster Events**: Rasio 16:9 atau 4:3, resolusi minimal `800 x 450 px`.
   * **Logo**: Transparan PNG atau SVG vector untuk ketajaman maksimal.
3. **Sistem Fallback Cerdas**:
   * Website telah diprogram dengan sistem *smart fallback*. Jika Anda belum menaruh file foto tertentu, website akan otomatis menampilkan inisial avatar atau ilustrasi vektor modern yang selaras tanpa error!
